# Insight Synapse
## Data Model Specification
### データモデル設計仕様書 v0.1

---

# 1. 目的

本ドキュメントは、Insight Synapseで扱う情報構造を定義する。

目的：

> AIの思考・判断・制作・評価・改善の過程を保存し、未来の判断品質向上に利用できるデータ構造を作る。

---

# 2. 基本思想

一般的なAI Memory：

```text
過去の会話保存
```

---

Insight Synapse Memory：

```text
思考状態

↓

判断過程

↓

結果

↓

評価

↓

学習パターン
```

---

保存する対象は、

「何を知っているか」

だけではなく、

「どう考えたか」

である。

---

# 3. データ階層

```text
Memory

├── State

├── Decision

├── Artifact

├── Evaluation

└── Pattern
```

# 4. State Model

## 役割

AIの現在状態を表現する。

---

ファイル：

```text
memory/state/current_state.yaml
```

---

形式：

```yaml
state:

  goal:
    value: ""

  phase:
    value: ""

  confidence:
    value: 0.0

  unknown_level:
    value: 0.0

  current_action:
    value: ""

  timestamp:
    value: ""
```

---

# 5. Thought Trace Model

## 役割

現在の思考経路を保存する。

Insight Synapse独自の重要データ。

---

ファイル：

```text
memory/traces/
```

---

形式：

```markdown
# Thought Trace


## Goal

何を達成するか


## Question

現在の問い


## Analysis

分析内容


## Hypothesis

仮説


## Decision

判断


## Confidence

確信度


## Next Action

次の行動
```

# 9. Pattern Model

## 役割

経験を抽象化する。

最重要Memory。

---

例：

失敗：

```text
初期案を急いで制作

↓

品質低下
```

↓

Pattern化：

```markdown
# Pattern


Situation:

未知領域


Problem:

調査不足


Lesson:

探索フェーズを追加する
```

# 11. Raw MemoryとIntelligent Memory

2種類に分ける。

---

## Raw Memory

生データ。

例：

- ログ
- 思考履歴
- 会話

---

## Intelligent Memory

抽象化された知識。

例：

- 成功パターン
- 判断基準
- 原則

---

構造：

```text
Raw Memory

↓

Extraction

↓

Intelligent Memory
```

---

# 13. Memory品質管理

保存基準：

```text
重要性

×

再利用性

×

改善効果
```

---

保存しないもの：

- 一時的情報
- 重複ログ
- 価値のない会話

# 20. 最終定義

Insight Synapse Data Modelとは、

> AIの知識だけではなく、思考状態・判断過程・評価結果・改善パターンを構造化し、知能の成長履歴として保存するためのデータ設計である。

このMemory設計によって、

Insight Synapseは、

**答えを保存するAIではなく、考え方を成長させるAI**

になる。
