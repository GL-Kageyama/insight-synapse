# Insight Synapse
## Technical Specification
### 技術仕様書 v0.1

---

# 1. 目的

本ドキュメントは、Insight Synapseを実装するための技術仕様を定義する。

目的：

> Insight Synapseの思想を、再現可能なソフトウェア構造へ変換する。

---

# 2. 基本設計方針

## 方針1

MVPでは複雑な基盤を作らない。

---

採用：

- Markdown
- YAML
- Git
- 軽量API

---

## 方針2

データは人間が読める形式で保存する。

理由：

- 監査可能
- 修正可能
- AI自身が理解可能

---

## 方針3

各Layerの責務を分離する。

---

# 3. 推奨技術スタック

## Runtime

候補：

```text
Python
```

理由：

- AI処理との親和性
- 豊富なライブラリ
- 実験容易性

---

## API Framework

候補：

```text
FastAPI
```

役割：

- Layer間通信
- 外部接続

---

## Data Storage

MVP：

```text

+

Git
```

将来：

```text
SQLite

↓

Vector Database

↓

Knowledge Graph
```

---

## Frontend

MVP：

```text
Simple Web UI
```

候補：

```text
React

または

Next.js
```

# 6. Workflow Engine仕様

Workflowは処理手順を管理する。

形式：

```yaml
workflow:

name:
creation

steps:

- research

- structure

- create

- evaluate
```

---

実行：

```text
Workflow

↓

Step取得

↓

Skill呼出

↓

結果保存
```

---

# 10. Memory仕様

Memory種類：

```text

├── state

├── traces

├── decisions

├── patterns

└── knowledge
```

---

```markdown

Decision:

Reason:

不確実性が高いため
```

# 18. 最終定義

Insight Synapse Technical Specificationとは、

> AIの思考構造を、実装可能なモジュール・データ・通信仕様へ変換するための技術設計書である。

本仕様の目的は、

「AIを動かすコードを書くこと」

ではなく、

**成長する知能構造を壊さず実装すること**

である。
