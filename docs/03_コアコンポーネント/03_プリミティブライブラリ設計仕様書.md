# 1. 目的

本ドキュメントは、Insight SynapseにおけるPrimitive（基本思考操作）の設計、分類、利用方法を定義する。

目的：

> AIの思考処理をブラックボックス化せず、再利用可能な最小単位へ分解する。

---

# 2. Primitiveの定義

Insight SynapseにおけるPrimitiveとは、

> 複雑な思考を構成する最小レベルの認知操作

である。

階層：

```text
Goal
↓
Workflow
↓
Skill
↓
Primitive
↓
Operation
```

---

# 3. Primitiveを作る理由

一般的なAI：

```text
文章生成
画像生成
コード生成
```

のように用途別に分かれる。

しかし、根底にある思考操作は共通している。

例：

文章制作：

- 分解
- 比較
- 抽象化
- 統合

システム設計：

- 分解
- 比較
- 抽象化
- 統合

つまり、

**汎用知能の基盤はPrimitive層に存在する。**

---

# 4. Primitiveの役割

Primitiveは、「どう考えるか」を定義する。

例：

問題：

「新サービスを考える」

内部処理：

```text
分解する
↓
比較する
↓
抽象化する
↓
再構成する
↓
評価する
```

# 8. Analysis Primitive

## 8.1 Decompose

### 分解

目的：

複雑な対象を要素化する。

入力：

```text
複雑な問題
```

出力：

```text
構成要素
```

利用例：

- 問題分析
- システム設計

## 8.2 Compare

### 比較

目的：

差異と共通点を抽出。

入力：

```text
A / B
```

出力：

```text
比較軸
```

## 8.3 Classify

### 分類

目的：

対象をカテゴリ化。

# 10. Transformation Primitive

## 10.1 Abstract

### 抽象化

具体例から本質を抜き出す。

例：

```text
複数サービス
↓
共通価値
```

## 10.2 Reframe

### 視点変更

問題設定を変える。

例：

```text
「売れない」
↓
「価値が伝わっていない」
```

## 10.3 Simplify

### 単純化

不要要素削除。

## 10.4 Synthesize

### 統合

分割した要素を新たな全体へ再構成する。

Abstract（抽象化）が本質を抜き出すのに対し、Synthesizeは要素を組み合わせて**新しいまとまり**を作る。

入力：

```text
複数の断片・観点
```

出力：

```text
統合された全体
```

利用例：

- 分析結果の統合
- 複数視点の集約
- 企画の再構成

MVPでは`generate`と組み合わせて「収束的思考」を担う。

# 12. Evaluation Primitive

## 12.1 Score

数値評価。

## 12.2 Critique

問題発見。

## 12.3 Verify

検証。

## 12.4 Evaluate

### 総合評価

成果物を複数軸で総合的に評価する。

Score（数値評価）が単一軸の採点であるのに対し、Evaluateは5軸（Quality/Logic/Creativity/Value/Risk）を統合し、overallスコアと改善点を出力する。

採点ルーブリックは `03_コアコンポーネント/00_数値定義書.md` に従う。

入力：

```text
成果物
```

出力：

```text
overallスコア + 改善点
```

MVPでは評価の中心的思考操作として`evaluate`を採用する。

## カタログ対応（正版）

全カタログ20種は6カテゴリで、MVP8種はそのサブセットである。

| カテゴリ | 全カタログ（20種） | MVP |
|:---|:---|:---:|
| Analysis | Decompose, Compare, Classify | decompose, compare |
| Generation | Generate, Combine, Expand | generate |
| Transformation | Abstract, Reframe, Simplify, Synthesize | abstract, reframe, synthesize |
| Reasoning | Infer, Deduce, Induce | — |
| Evaluation | Score, Critique, Verify, Evaluate | evaluate |
| Reflection | Reflect, Extract Pattern, Update Belief | reflect |

> MVP8種の各Primitiveは必ず上表のカタログに対応する。カタログに無いPrimitiveをMVPへ追加する場合は、先に本書を改版してから追加する。

# 23. 最終定義

Insight Synapse Primitive Libraryとは、

> AIの思考処理を最小単位へ分解し、組み合わせ可能な知的操作として管理する基盤である。

Skillは「何ができるか」。

Agentは「誰が判断するか」。

Primitiveは、

**「どう考えるか」**

を定義する。
