# Insight Synapse
## Skill Architecture Specification
### スキルアーキテクチャ仕様書 v0.1（統合版）

> 旧版2ファイル（Skill System Specification / Skill Architecture Specification）を統合した版。階層は5階層、MVP構成は question / analyze / structure / create / evaluate / reflect に一本化。

---

# 1. 目的

本ドキュメントは、Insight SynapseにおけるSkillの役割、設計原則、構造、管理方法を定義する。

目的：

> AIの能力を再利用可能な単位として整理し、制作・分析・評価を柔軟に組み合わせられる能力体系を構築する。

---

# 2. Skillの定義

Insight SynapseにおけるSkillとは、

> 特定の目的達成のために、Primitiveを組み合わせて構成された再利用可能な能力単位

である。

SkillはAIの「人格」ではなく、

**能力モジュール**

として扱う。

構造：

```text
Goal
↓
Workflow
↓
Skill
↓
Primitive
↓
Execution
```

---

# 3. Skillの役割

Skillは、「何をする能力か」を定義する。

例：

- 分析する
- 問いを作る
- 構造化する
- 制作する
- 評価する

---

# 4. Skill・Agent・Primitiveの違い

## Primitive

### 定義

最小思考操作。

例：

```text
分解
比較
抽象化
再構成
推論
統合
```

## Skill

### 定義

複数Primitiveを組み合わせた能力。

例：

```text
Research Skill
↓
Search
↓
Compare
↓
Summarize
```

## Agent

### 定義

独立した判断主体。

例：

```text
Critic Agent
Research Agent
Specialist Agent
```

## 関係

```text
Orchestrator
↓
Agent
↓
Skill
↓
Primitive
```

またはMVPでは、

```text
Orchestrator
↓
Skill
↓
Primitive
```

で十分。

---

# 5. 基本設計思想

Skillは増やしすぎない。

理由：

能力を細分化しすぎると、

- 管理コスト増加
- 組み合わせ爆発
- 判断困難

が発生する。

また、制作は一つの万能Skillでは作らない。

悪い構造：

```text
Create Everything Skill
```

理由：

- 判断不能
- 改善不能
- 再利用困難

良い構造：

```text
Concept
↓
Structure
↓
Generate
↓
Refine
↓
Evaluate
```

# 11. Skill内部構造

各Skillは統一形式にする。

```text
skills/
└── question/
    ├── skill.md
    ├── input.yaml
    ├── output.yaml
    └── examples/
```

skill.mdの例：

```markdown
# Question Skill

## Purpose
問題を明確化する。

## Input
- Goal
- State

## Process
1. Unknown抽出
2. 質問生成
3. 優先順位付け

## Output
Question List
```

# 18. SkillとAgentの使い分け

Skillを使う：

- 手順が明確
- 再利用可能
- 判断不要

Agentを使う：

- 専門判断が必要
- 独自視点が必要
- 結論責任がある

# 21. 設計ルール

## Rule 1

Skillに人格を持たせない。

## Rule 2

Skillに最終判断を持たせない。

## Rule 3

Skillは再利用可能にする。

## Rule 4

Skill追加前にPrimitiveで表現できないか確認する。

# 23. 最終定義

Insight Synapse Skill Architectureとは、

> AIの能力を再利用可能な単位に分解し、目的に応じて柔軟に組み合わせるための能力管理体系である。

SkillはAIの「技能」であり、Primitiveは「思考の筋肉」、Agentは「専門的な判断主体」である。

Insight Synapseは、この3層を分離することで、拡張可能な知的システムを構築する。
