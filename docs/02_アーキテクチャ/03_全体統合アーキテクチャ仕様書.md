# Insight Synapse
## System Integration Architecture Specification
### 全体統合アーキテクチャ仕様書 v0.1

---

# 1. 目的

本ドキュメントは、Insight Synapseを構成する各レイヤーを統合し、全体システムの動作原理を定義する。

目的：

> AIを単なる生成システムではなく、思考・判断・制作・評価・改善を循環する知的システムとして構築する。

# 4. 各レイヤー役割

---

## Layer 1
### Human Interface

### 役割

人間との接点。

担当：

- Goal入力
- 状態確認
- 判断承認
- 修正指示

---

## Layer 2
### Orchestrator

### 役割

知的制御中枢。

担当：

- 状態判断
- 思考コスト判断
- Workflow選択
- Skill選択
- Agent利用判断

---

定義：

> 「何をするか」ではなく「どう考えるべきか」を決定する層。

---

## Layer 3
### Workflow Engine

### 役割

目的達成までの経路管理。

例：

```text id="q8v3m5"

↓

↓

Create

↓

Evaluate
```

---

## Layer 4
### Skill Layer

### 役割

再利用可能な能力。

例：

- Analyze
- Create
- Critique
- Reflect

---

## Layer 5
### Primitive Layer

### 役割

最小思考操作。

例：

- 比較
- 抽象化
- 再構成

## Layer 6
### Agent Layer

### 役割

専門的判断主体。

利用例：

- 研究
- 専門分析

---

### Evaluation Engine

### 役割

Logic

Creativity

Value

---

## Layer 8
### Memory System

### 役割

経験保存。

保存：

- 思考軌跡
- 判断理由
- 成功パターン
- 失敗パターン

---

## Layer 9
### Policy Layer

### 役割

システムの方向性維持。

管理：

- 判断基準
- 品質基準

# 15. 最終定義

Insight Synapseとは、

> AIの生成能力を中心にしたシステムではなく、目的理解・思考選択・制作・評価・経験蓄積を循環させることで、継続的に知的能力を向上させる認知アーキテクチャである。

核心概念：

**生成するAIから、成長するAIへ。**
